## Commands

**Development**
- `npm run dev` - dev server on port 3000
- `npm run build` - production build
- `npm run serve` - preview production build

**Code Quality**
- `npm run test` - run all tests with vitest
- `npm run lint` - lint with biome
- `npm run format` - format with biome
- `npm run check` - check all (format + lint) with biome

**Deployment**
- `npm run deploy` - deploy via wrangler (Cloudflare)

**Testing Single Files**
- `npx vitest run <file-path>` - run specific test file

## Architecture

**TanStack Start SSR App** - Full-stack React framework with file-based routing, SSR/SSG, and type-safe APIs

**Core Stack**
- TanStack Router - file-based routing with SSR/SSG (`src/routes/`, `routeTree.gen.ts`)
- TanStack Query - server state with SSR integration via `setupRouterSsrQueryIntegration`
- TanStack DB/React DB - local-first data layer with collections
- TanStack Form - form state management
- Better Auth - authentication (session refresh disabled)
- shadcn/ui - UI components (New York style)
- Tailwind CSS v4 - styling
- Vite - build tool
- Biome - formatting/linting (tabs, double quotes)

**Router Integration** (`src/router.tsx`)
- Router created via `getRouter()` factory
- QueryClient passed through router context for SSR data prefetching
- `Wrap` component provides TanStack Query context to router tree
- SSR-Query integration enables server-side data fetching

**Collections** (`src/db-collections/`)
- Local-first data via `@tanstack/react-db`
- Define with Zod schemas and `createCollection()`
- Example: `messagesCollection` with `localOnlyCollectionOptions`

**Path Aliases**
- `@/*` maps to `src/*` (configured in tsconfig.json + vite-tsconfig-paths)
- shadcn imports: `@/components/ui/*`, `@/lib/utils`

**Root Route** (`src/routes/__root.tsx`)
- Defines global layout with Header component
- Configures TanStack DevTools (Router, Query, React DB)
- Sets meta tags and CSS imports

**Biome Config**
- Tabs for indentation, double quotes
- Auto-organize imports
- Ignores `routeTree.gen.ts` (generated by router plugin)
